# Media Downloader

Chrome / Edge Manifest V3 擴充套件，用於在瀏覽支援頁面時，手動下載目前看到的圖片、影片與動態媒體。現階段支援 `x.com`。

## 功能

- 單張圖片下載：最大可用尺寸 / 網頁目前顯示尺寸。
- 同一篇貼文 2–4 張圖片可合併成單一圖片下載。
  - 自動依目前頁面排列判斷左右 / 上下；3–4 張採 2 欄網格。
  - 可手動指定左 → 右或上 → 下。
  - 合併時可選最大尺寸或網頁目前尺寸。
- JPEG 統一使用 `.jpg`，避免瀏覽器存成 `.jfif`。
- 一般影片下載最高可取得的 MP4。
- 短動態媒體可在本機轉成真正的 `.gif`。
  - 最長秒數可調 1–30 秒，超過時保留 MP4。
  - GIF 尺寸縮放可調 10–100%。
  - GIF FPS 可調 5–30。
  - V0.5.2 起改用每幀自適應 256 色調色盤與 Floyd–Steinberg dithering，降低色塊與色階失真。
- 圖片 / MP4 / GIF / 合併圖使用同一下載位置。
- 所有合併與 GIF 轉檔皆在本機瀏覽器內完成。

## V0.5.2

- 修正 GIF 轉檔嚴重色塊 / 色階失真問題。
- GIF 改用每幀自適應 256 色調色盤。
- 加入 Floyd–Steinberg 色彩抖動。
- 改善 GIF LZW 壓縮，降低不必要的檔案膨脹。
- 圖片、影片、多圖合併及既有設定行為維持不變。

## 安裝

1. 下載或 clone 此 Repository。
2. 開啟 `chrome://extensions/`，或 Edge 的擴充功能管理頁面。
3. 開啟「開發人員模式」。
4. 選擇「載入未封裝項目」。
5. 選擇本專案資料夾。
6. 回到支援頁面後重新整理。

## 下載位置限制

Chrome 對桌面、下載等部分系統資料夾可能限制 File System Access API 授權。未指定自訂資料夾時，擴充套件會使用瀏覽器預設下載位置。
